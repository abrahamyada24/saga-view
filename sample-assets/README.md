# Sample Assets untuk Uji Lokal

Folder ini berisi file fisik untuk mencoba flow seperti file asli.

## Folder Foto

Pilih folder ini saat klik `Pilih Folder Foto`:

```text
sample-assets/photos-customer-demo
```

Isi:
- 10 file PNG simulasi foto customer.
- Nama file sudah berurutan `IMG_0001.png` sampai `IMG_0010.png`.

## Frame PNG Transparan

Import file ini di `Frame Manager`:

```text
sample-assets/frames/FRAME_PROOF_4_SLOT_TRANSPARENT.png
```

Isi:
- PNG transparan dengan 4 area slot.
- Gunakan `Import Frame PNG`, lalu koreksi slot jika auto-detect belum pas.

## Alur Uji Real Picker

1. Jalankan `START-PROTOTYPE-WINDOWS.cmd`.
2. Buka `Session`.
3. Klik `Pilih Folder Foto`.
4. Pilih `sample-assets/photos-customer-demo`.
5. Buka `Frame Manager`.
6. Klik `Import Frame PNG`.
7. Pilih `sample-assets/frames/FRAME_PROOF_4_SLOT_TRANSPARENT.png`.
8. Lanjutkan customer flow sampai `Export PNG Sekarang`.
